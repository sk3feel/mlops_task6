# Домашнее задание 6

Проверка доступа к Claude (Anthropic): от запроса пользователя до разрешения или ограничения доступа. Авторизация, оплата, ответы Claude и апелляции не рассматриваются.

Модель по стране IP, типу сети и истории входов за 30 дней оценивает риск входа из неподдерживаемого региона. Сервис решений получает риск от 0 до 1 и версию модели либо ошибку. Это нужно, чтобы сократить ручные проверки и ошибочные ограничения.

- Риск < 20%: разрешить доступ.
- 20% ≤ риск < 90%: ручная проверка.
- Риск ≥ 90%: ограничить доступ до пересмотра.
- Ошибка, неверные данные, нет модели или ответа за 3 секунды: ручная проверка.

При ручной проверке запрос ждёт решения специалиста. Для обучения берутся проверенные результаты. Другой специалист проверяет часть автоматических решений: сами по себе ответы модели не считаются правильной разметкой.

## Допущения

- Технологии, признаки, пороги и порядок проверок выбраны для ДЗ.
- История входов, разметка и первая модель уже есть.
- Специалист может вручную проверить регион.

Схемы и устройство системы предложены в этой работе. Реальная архитектура Anthropic неизвестна.

## Связь BPMN и C4

- Вызов модели и выбор действия: сервис решений и сервис модели.
- Ручная проверка: специалист через интерфейс сервиса решений.
- Сообщение решения: сервис решений → сервис доступа Claude.
- Сохранение результата: хранилище истории проверок и разметки. Эти данные использует сервис обучения модели.
